# Contributing

Contributions are welcome for educational and portfolio purposes.

1. Create a focused branch and explain the banking or analytical rationale.
2. Preserve the human-led decision boundary and synthetic-data classification.
3. Add tests for policy, model or data-contract changes.
4. Run `make lint`, `make coverage` and `make demo`.
5. If you changed any tracked file, run `make manifest` and then `make verify`; CI fails when
   `MANIFEST.sha256` does not match the committed files.
6. Update methodology, model or governance documentation when assumptions change.

Do not add personal data, confidential bank information, credentials, unlicensed datasets or
claims of regulatory compliance.
